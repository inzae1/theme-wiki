# 개별의테마천국 위키

단톡방 참여자 12명의 대화 캐릭터를 소개하는 인물도감과 위키입니다.

## 기능

- 인물 카드와 인물별 상세 문서
- 이름·별명·성향 검색 및 그룹별 필터
- 인물 2명 비교
- 브라우저 로컬 북마크
- 서로 다른 얼굴 특징의 창작 아바타 12종
- 모바일 반응형 레이아웃

## 실행

별도 빌드나 의존성 설치 없이 정적 파일을 제공합니다.

```bash
python3 -m http.server 8080 --directory dist
```

브라우저에서 http://localhost:8080 을 엽니다.

## 파일 구성

- `dist/index.html`: 페이지 셸, 제목 및 메타데이터
- `dist/style.css`: 반응형 스타일
- `dist/app.js`: 검색, 문서, 비교 및 북마크
- `dist/data.js`: 기존 분석에서 전달된 인물별 콘텐츠와 수치
- `dist/assets/avatars-v2.png`: 현재 사용 중인 캐릭터 아바타 아틀라스
- `.openai/hosting.json`: 기존 Sites 배포 설정

## 데이터 기준

내용과 수치는 이전 대화에서 전달된 분석을 인용했습니다. 전체 CSV 재집계 또는 성격 진단 결과가 아닙니다. 원본 대화 CSV는 포함하지 않습니다. 아바타는 실제 외모와 무관한 창작물입니다. 개인별 분석이 포함되어 있으므로 이 저장소는 비공개로 유지합니다.
