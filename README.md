# 개테천위키

12명의 이름·나이·MBTI·취미·성향·비슷한 인물을 정리한 인물 위키입니다.

사이트: https://inzae1.github.io/theme-wiki/

## 기능

- 나무위키식 인물 문서: 기본 정보 표, 목차, 취미·성향, 비슷한 인물, 관계
- AI 재판소: 8개 대표 사건의 기록 기반 모의 판결, 변론·재심, 판결문 복사와 최근 기록
- 사건·에피소드 모음: 대표 사건 8건과 일반 에피소드 14건, 종류·분야·인물·검색어 필터와 이야기 저장
- 인간관계 지도: 인물 선택, 연결 강조, 두 사람 공통 관심사·관계 비교, 관계 링크 공유
- 이름·MBTI·취미 검색, 분류·정렬, 북마크, 모바일 대응

## 대표 사건 재분석

기존 카페 산책·MBTI 변경·러닝 제안·선수 평가·주차 고생담은 대표 사건에서 제외했습니다. MBTI와 스포츠 취향은 인물 정보에 유지합니다.

대표 사건은 무안참사 스페어처리, 장모·시어머니 호칭 혼동, 홍대 오뎅 구조 발언, 허니콤보·레드콤보 발언, 인왕산 리벤지, 광주 식사 계획, 애슐리 메뉴 대치, 부산·구미 선약 이탈의 8개입니다. 대표 사건 8건과 추가 에피소드 14건에 대해 38개 날짜의 76개 대화 구간을 대조했습니다. 구간 수는 사건 발생 횟수나 전체 재언급 횟수가 아닙니다.

다른 날짜의 재언급과 동행인의 구체적 상호 확인을 우선했습니다. 동일 여행의 작은 장면은 묶고, 서로 다른 부산·구미 여행은 구분합니다. 봇 응답·자동 요약·뉴스·외부 인물과 동음이의어는 사건 근거에서 제외합니다. 애슐리 콜은 식사 사건이 아니며, 인왕산 등정 실패 예정이라는 농담은 실제 당일 등반 실패 기록이 아닙니다.

사용자가 보충한 네 발언의 맥락과 CSV에서 직접 확인한 내용을 구분합니다. 공유 사진과 최초 캡처 내용은 미확인이고, 반복 회상과 당사자의 이견을 함께 보존합니다. `data/case-evidence.json`에는 원문 없이 대조한 CSV 레코드 범위·날짜·사용자 보충 설명의 구분을 남겼습니다. 화면에는 요약과 사건 흐름을 표시합니다.

## 에피소드 확장

대표 사건 8건만 남겨 일반 모임·게임 경험이 지나치게 줄어든 점을 보완했습니다. 에피소드는 반복 날짜가 하나여도 구체적인 경험과 여러 사람의 설명이 있으면 별도로 수록합니다. 단순 약속·일반 취향·같은 사건의 장면 쪼개기는 추가하지 않습니다. 에피소드에는 피고인이나 판결 대신 별도 읽기 화면을 제공합니다.

추가한 14건: 한 점 차 볼링, 부산 음식 코스, 하루방 평가, 폴앤메리 대기, 대전 오토체스 모임, 동행·래미안 모임 시절, 고척 뒤 4대4 롤 내전, 결승 공동 관람, 서바이벌 모임, 로아 접속 대기열, 진힐라 미션 확인, 직관 승률 대화, 북한산 등산, 야구 관람 뒤 대구 막창 식사.

주차 상황은 취향으로 쓰지 않으며 최현석 소개와 주차에만 근거한 관계 설명에서도 제거했습니다.

## 데이터와 해석

2023-08-07~2026-10-19 CSV 1,774,790건을 구조적으로 읽고 검색했으며 12명 메시지 합계는 1,694,291건입니다. 모든 메시지의 의미를 빠짐없이 읽은 전기는 아닙니다. 원본 CSV·분석 DB·채팅 원문 목록은 배포 파일에 포함하지 않습니다. 기존 Git 기록에는 이전 버전의 선별 인용이 남아 있을 수 있습니다.

확인된 생년월일은 없어 나이는 미상입니다. 프로필에서 입력하면 만 나이를 계산하며 현재 브라우저에만 저장합니다. MBTI는 당시 자기표현과 검사 기록으로 현재 유형이나 심리 상태를 진단하지 않습니다. 성향은 선별된 취미와 대화 참여 방식의 편집 요약입니다. 비슷한 인물은 공통 취미 태그당 3점, 기존 관계가 있으면 1점을 반영해 정렬하며 성격 궁합 점수가 아닙니다.

관계 지도는 정리된 관계 요약만 사용합니다. 위치·거리·선의 굵기는 친밀도를 뜻하지 않습니다. 기록이 없는 것을 관계가 없는 것으로 해석하지 않습니다. 아바타는 실제 얼굴과 무관한 창작물입니다.

## 재판소와 저장의 범위

현재 재판소는 실시간 AI 모델 호출 없이 검토한 사건별 규칙과 판결문을 사용합니다. 새 사건, 피고인·사건 내용 변경, 추가 변론은 확인할 수 없는 주장으로 처리해 판단을 보류합니다. 화면에도 실시간 AI 연결이 없음을 표시합니다. 분위기는 문체만 바꾸고 사실 판단은 바꾸지 않습니다. 실시간 생성형 판결에는 서버 측 AI 연동이 필요하며 API 키를 브라우저 코드에 넣지 않습니다.

북마크, 생년월일, 판결 기록(최근 12건), 배심원 의견, 전시 저장은 현재 브라우저의 localStorage에 저장합니다. 서버 공유·친구 간 동기화·공동 투표는 없습니다. 편집 기준 화면에서 이 사이트가 저장한 데이터만 초기화할 수 있습니다.

## 실행과 검증

```sh
python3 -m http.server 8080 --directory dist
node scripts/verify.mjs
```

별도 빌드나 의존성이 없는 HTML/CSS/JavaScript 사이트입니다. `dist/data.js`는 공개용 프로필·사건 요약, `dist/app.js`는 화면과 상호작용, `dist/style.css`는 스타일입니다. `main` 변경 시 GitHub Actions가 `dist`를 GitHub Pages로 배포합니다.

## 모임 생존게임 · 전국 원정 편

멤버 셋을 먼저 정하고 지도에서 도시를 고릅니다. 12개 도시 중 후보 5곳을 제시하며, 세부 동네는 모임 시작 시 27곳 중 해당 도시의 후보로부터 추첨합니다. 같은 지역 재시작도 장소를 다시 뽑습니다. 대표 도시 좌표와 사용자 제공 거주지로 이동 부담을 추정하며 실제 운행 시간·요금이 아닙니다. 지역별 관광 출처는 게임의 자료 패널에 있습니다.

화면마다 세 개의 짧은 선택지만 보여 줍니다. 전체 행동 40개에는 김밥천국·큰맘할매순대국·한솥·홍콩반점·롯데리아와 편의점 컵라면 제안도 있습니다. 브랜드·메뉴 참고 출처는 `data/game-food-chains.json`이며 방문 지점과 지출은 게임 창작입니다.

지역 사건 54개, 대기·걷기·예산·합류 갈등 4개, 20개 엔딩을 제공합니다. 도착·합류 사건은 점심 전에, 이후 사건은 오후 코스 이후에 배치합니다. 한 사건의 문제 제기와 선택별 반응은 같은 화자 역할을 유지합니다. 선택한 체인은 카페·귀가·일부 엔딩에서 다시 언급합니다. 갈등이 누적되면 인물별 거리 부담과 편집 성향에 따라 이탈하거나 맞짱·가방 투척 엔딩으로 끝날 수 있습니다. 모든 사건과 대사는 창작입니다.

### 말투 분석 → 대사 작성 → 변형

1. `data/game-voice-profiles.json`: 인물별 집계와 무작위·질문형 표본, 연속 문맥을 LLM이 읽어 만든 편집 분석입니다. 전체 대화를 의미 분석하거나 모델을 학습한 결과는 아닙니다. 봇 명령·미디어 표시는 통계에서 제외했습니다.
2. `data/game-conversations-source.json`, `data/game-conversations-variants.json`, `data/game-episode-alternates.json`, `data/game-episode-more.json`, `data/game-ending-scenes.json`: 장면 전체의 문답과 선택별 후속 반응입니다. 웃음만 보내는 메시지, 문장 앞뒤 웃음, ~임?·~노·~나·~잔슴 등을 구분합니다.
3. `data/game-voice-phrases.json`: 검토한 인물별 표현입니다. `data/game-community-style.json`의 디시 글은 창작 문체 참고이며 실제 인물 정보의 근거가 아닙니다.
4. `data/game-sidechat.json`: 비참여자 둘이 게임·야구·음식 등 딴얘기를 하고 참석자가 현재 선택으로 돌아오는 14개 주제입니다. 본문 외 대체 문답도 준비했습니다.

367개 문맥에 완결된 대화를 제공합니다. 일반 사건 64개(지역 54개·연결 갈등 4개·공통 위기 6개)는 도입과 세 가지 선택별 반응마다 3벌, 일정 행동 40개도 각각 3벌입니다. 엔딩 20종은 각각 10벌, 총 200개의 완결된 후일담을 갖습니다. 나머지 도입·불참자 대화·콜백은 2~3벌입니다. 기본 발화 1,075개와 추가 발화 2,464개를 각각 12명 말투로 준비합니다. 새 모임의 대사 차수는 30회 순환하며 2·3·10벌 선택에 모두 적용합니다. 같은 파티·장소를 연속 재시작하면 같은 문맥의 대체 대사를 고르고, 저장 복원에서는 같은 대사가 유지됩니다. 준비된 대사는 유한하며 실시간 LLM·API 키·서버 호출이 없습니다. 문장 일부를 실행 중 무작위로 섞거나 어미를 붙이지 않습니다.

호칭은 원문 문두의 명시적 호칭을 집계한 참고 자료만 보존합니다. 답변에 이름이나 호칭을 자동으로 끼워 넣지 않습니다. 인물 성향 수치는 숨겨진 게임 편집 설정이며 성격 진단·측정값이 아닙니다. 원문 채팅·분석 DB는 배포하지 않습니다.

### 생성과 확인

```sh
python3 scripts/build-game-districts.py
python3 scripts/compile-game-voices.py
node scripts/verify.mjs
node scripts/verify-game.mjs
```

검사는 실제 화면에 나오는 세 선택지로 여행을 실행해 엔딩·지역 사건 도달, 인물·장소 일관성, 저장 복원, 문맥별 대체 대사와 앞선 선택의 재등장을 확인합니다. 검사 통과는 실제 친구 말투의 완벽한 재현을 보증하지 않습니다.
