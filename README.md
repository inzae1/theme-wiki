# 개테천위키

12명의 이름·나이·MBTI·취미·성향·비슷한 인물을 정리한 인물 위키입니다.

사이트: https://inzae1.github.io/theme-wiki/

## 기능

- 나무위키식 인물 문서: 기본 정보 표, 목차, 취미·성향, 비슷한 인물, 관계
- AI 재판소: 검토한 5개 사건의 모의 판결, 변론과 재심, 판결문 복사, 최근 기록
- 흑역사 박물관: 가벼운 사건 요약, 분류와 전시 저장
- 인간관계 지도: 인물 선택, 연결 강조, 두 사람 공통 관심사·관계 비교, 관계 링크 공유
- 이름·MBTI·취미 검색, 분류·정렬, 북마크, 모바일 대응

## 데이터와 해석

2023-08-07~2026-10-19 CSV 1,774,790건 중 기존에 선별한 12명 자료를 사용합니다. 12명 메시지 합계는 1,694,291건입니다. 원본 CSV·분석용 DB·채팅 인용 원문은 배포 파일에 포함하지 않습니다. 기존 Git 기록에는 이전 버전의 선별 인용이 남아 있을 수 있습니다.

나이는 확인된 생년월일이 없어 미상입니다. 사용자가 프로필에 생년월일을 입력하면 만 나이를 계산하며 현재 브라우저에만 저장합니다. MBTI는 당시 자기표현과 검사 기록으로, 현재 유형이나 심리 상태를 진단하지 않습니다. 성향은 선별된 취미와 대화 참여 방식의 편집 요약입니다. 비슷한 인물은 공통 취미 태그당 3점, 기존 관계가 있으면 1점을 반영해 정렬합니다. 성격 궁합 점수가 아닙니다.

관계 지도는 기존 관계 요약만 사용합니다. 위치·거리·선의 굵기는 친밀도를 뜻하지 않습니다. 기록이 없다는 이유로 관계가 없다고 판단하지 않습니다. 아바타는 실제 얼굴과 무관한 창작물입니다.

## 재판소 구현 범위

이 버전의 AI 재판소는 실시간 AI 모델 호출 없이 사건별로 검토한 규칙과 판결문을 사용합니다. 새 사건, 피고인·사건 내용 변경, 추가 변론은 확인할 수 없는 주장으로 처리해 판단을 보류합니다. 화면에도 실시간 AI 연결이 없음을 표시합니다. 분위기 선택은 문체만 바꾸고 사실 판단을 바꾸지 않습니다. 실시간 생성형 판결을 추가하려면 서버 측 AI 연동이 필요합니다. API 키를 브라우저 코드에 넣지 않습니다.

북마크, 생년월일, 판결 기록(최근 12건), 배심원 의견, 전시 저장은 현재 브라우저의 localStorage에 저장합니다. 서버 공유·친구 간 동기화·공동 투표는 없습니다. 편집 기준 화면에서 이 사이트가 저장한 데이터만 초기화할 수 있습니다.

## 실행과 검증

```sh
python3 -m http.server 8080 --directory dist
node scripts/verify.mjs
```

별도 빌드나 의존성이 없는 HTML/CSS/JavaScript 사이트입니다. `dist/data.js`는 공개용 프로필·사건 요약, `dist/app.js`는 화면과 상호작용, `dist/style.css`는 스타일입니다. `main` 변경 시 GitHub Actions가 `dist`를 GitHub Pages로 배포합니다.
