# 개별의테마천국 위키

실제 단톡방 기록에서 정리한 12명의 취향·관계·옛날 사건 위키.

사이트: https://inzae1.github.io/theme-wiki/

## 구성
- 인물 12명: 취향·취미, 축구 취향, 실제 대화 기반 관계, MBTI 자기소개 기록
- 에피소드 13개: 여행·모임·게임·맥주 이야기와 서로 다른 회상
- 선별한 근거 메시지 151개: 발신자·날짜·CSV 레코드 번호
- 관심 분야 키워드 집계, 직접 @멘션 집계 (친밀도나 선호 점수 아님)
- 검색, 분류, 북마크, 두 사람 비교, 모바일 대응

## 데이터 기준
제공된 2023-08-07~2026-10-19 CSV의 1,774,790개 레코드를 프로그램으로 읽고, 12명의 메시지를 집계했다. 사건·취향·MBTI 키워드 후보는 주변 대화를 함께 검토했다. 모든 문장의 의미를 빠짐없이 분석한 전기는 아니다. 원본 CSV와 분석용 DB는 저장소에 포함하지 않는다.

사건 날짜는 대화 날짜이며 실제 발생일이 아닐 수 있다. 제안과 실제 실행은 구분한다. MBTI가 여러 번 다르게 나오거나 기록이 없으면 그대로 표시한다. 아바타는 실제 얼굴과 무관한 창작물이다.

## 실행
```sh
python3 -m http.server 8080 --directory dist
```

별도 빌드 과정이 없는 HTML/CSS/JavaScript 사이트. `dist/data.js`에 선별 데이터와 근거, `dist/app.js`에 화면과 검색, `dist/style.css`에 스타일이 있다.

`main`에 변경하면 `.github/workflows/pages.yml`이 `dist`를 GitHub Pages에 자동 배포한다.
