# 양영준 · 기사 계열 전투와 전용 원화 (r87)

캐릭터·직업·스킬 ID, 전직 구조, 강화 단계, 저장 데이터는 유지한다.

## 전투 판정

- 무적·회피 시 방어 피해 축적과 응징 반격이 발생하지 않는다. 방어력 적용 후 실제 체력/보호막 피해가 감소한 만큼만 축적한다. 옛 공통 자동 반격과 기사 전용 반격이 중복되던 경로도 제거했다.
- 관통창은 작은 구간으로 지형을 검사해 벽에서 멈춘다. 렌더링 길이도 같은 종료점을 사용하고 실제 명중 위치에 별도 타격을 표시한다. 브레스·발톱의 부채꼴과 반격도 시야를 검사한다.
- 돌파의 맹세·성전 돌격은 순간 위치 이동 대신 제한된 속도로 실제 경로를 이동하며 적마다 한 번만 타격한다. 벽에 닿으면 멈춘다.
- 크루세이더 성전 개시는 기본공격 명중 시에도 성화 흔적을 설치해 정지 보스전에서 작동한다. 겹친 성화는 같은 적에게 0.6초에 한 번만 피해를 준다. 기존 기본공격 추가 파동은 유지한다.
- 브레스는 0.35초 준비 후 피해가 발생한다. 실제 반경 250·각도 1.6라디안의 부채꼴로 그림을 잘라 범위 밖으로 나가지 않게 한다.

## 전용 원화·GIF

내장 이미지 생성 도구로 두 원화를 제작했다. 게임은 투명 PNG의 프레임을 실제 판정에 맞춰 재생하고, 같은 원화로 GIF도 저장한다.

- 원화: `dist/rpg-fx/knight/knight-source.png` (4열×7행)
- 전용 이펙트: 기사 금속 방패/검격, 팔라딘 성검 심판, 드래곤나이트 화염 브레스, 크루세이더 성전 화염, 템플러 갑주 파편 방출, 드래곤랜서 정밀 창 관통, 용혈기사 용린/발톱 각성.
- 게임용 애니메이션: `dist/rpg-fx/knight/knight-atlas.png`
- 직업별 GIF: 같은 폴더의 `기사.gif`, `팔라딘.gif`, `드래곤나이트.gif`, `크루세이더.gif`, `템플러.gif`, `드래곤랜서.gif`, `용혈기사.gif`.
- 원화의 크루세이더 첫 칸에는 삽화형 인물이 있어 사용하지 않는다. 깃발·화염만 있는 나머지 프레임으로 게임과 GIF를 구성한다.
- 반룡 원화: `dist/rpg-fx/knight/half-dragon-source.png`. 기존 머리·윙크·얼굴을 보존한 4프레임 갑주/발톱/날개 외형이다.
- 반룡 게임 외형: `dist/rpg-pixels-v2/characters/youngjun-dragon.png`; 미리보기 GIF: `dist/rpg-fx/knight/반룡화.gif`.
- 프롬프트: `knight-prompt.txt`, `half-dragon-prompt.txt` (동일 폴더).
- 재생성/패킹: `scripts/build-rpg-knight-art.py`.

반룡화는 기존 본체에 날개만 붙이지 않고 해당 외형으로 교체한다. 대기·이동·기본공격·기술 모션과 프레임을 연결했으며, 변신 종료 시 원래 외형으로 돌아온다. 게임, 캐릭터 미리보기, 스킬 실험실, 레이드 시각 렌더러에 적용한다. 레이드 실제 피해와 보상은 기존 서버 판정을 유지한다.

## 검증

`verify-rpg-knight.mjs`: 28기술, 7직업 자동 보스전, 가장 강한 방어 유지, 실제 방어량, 무적/회피 반격 차단, 지형을 막는 양쪽 창 분기, 연속 돌진과 이동량 제한, 정지 상태의 성화/중첩 방지, 브레스 준비 시간, 실제 반룡 외형 상태와 종료.

기존 검사·전사·궁수·윤인재·슬롯 강화·스킬 치명타 검사, 336스킬 실험실 및 레이드 렌더링 검사, 업데이트 검사도 통과했다. 실제 브라우저에서 새 반룡 외형을 확인했으며 콘솔 오류가 없었다.
