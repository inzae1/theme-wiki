# 강화 골드 비용 개편

상태: 로컬 코드 반영 및 전용 검증 완료. 웹 배포는 아직 하지 않음.

목표는 골드를 기본 수수료로, 강화석을 고강 도전 재료로 쓰게 하는 것이다. 성공 확률·대성공·대실패와 강화석 요구량은 유지한다.

- +0~19 비용 유지: 35 + 12 × 현재강화² 골드.
- +20 이상: 4,367 + 600 × 초과단계 + 20 × 초과단계². 초과단계 = 현재강화 − 19.
- 실패 및 대실패: 결제 골드의 70%를 정수 내림하여 즉시 반환. 강화석 전량 소모. 성공·대성공은 전액 소비.
- 시도하려면 선결제 골드 전액이 필요하다. 환급은 결과와 동시에 저장한다.
- 기존 캐릭터 재화·강화 단계는 그대로 유지하며 과거 지출 환급은 적용하지 않는다.
- 재료 표시 아래에 실패 실제 골드 소모, 현재 단계 비용 기준 시도 가능 횟수(환급 제외)를 표시한다. 단계가 오르면 다음 비용으로 다시 계산한다.

## 검증

전용 강화 경제 검사와 기존 슬롯 강화 검사 통과: 50단계 모든 확률 구간, 성공·대성공·실패·대실패의 골드·강화석 정산, 재화 부족 시 변경 없음, UI 환급·시도 횟수, 저장 검증.

기존 종합 verify-rpg.mjs는 시작부에서 스프라이트 프레임 개수 기대값 204 / 실제 228 불일치로 중단됐다. 강화 비용 변경 전부터 누적된 데이터 기대값 문제로, 이 작업에서 해당 기대값은 바꾸지 않았다.
