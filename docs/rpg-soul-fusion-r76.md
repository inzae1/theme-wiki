# 사원소 융합·진혼악사·리치 변경

## 하모니스트

평소에는 불(광역 폭발), 물(둔화), 바람(직선 관통), 대지(근접 강타와 짧은 제어) 정령을 유지한다. 사원소 협공과 원소 공명은 네 정령을 소모하지 않는다. 궁극기는 네 정령을 8초간 하나의 융합체로 바꾸고, 종료 시 네 정령을 다시 생성한다. 자동 궁극기는 사원소 소환 또는 복귀 후 최소 6초, 보스 또는 주변 적 3마리 이상일 때 사용한다. 사망·전환 중에는 분리로 정령을 다시 만들지 않는다. 미리보기는 궁극기 종료와 분리까지 재생한다.

## 남지훈 · 진혼악사

기존 리치의 소환 행동·배율·지속시간·비용·쿨타임을 이전했다. 망자의 악단은 병사 3·궁수 3·좀비 2, 묘지의 수호자는 골렘, 장송 지휘는 소환체 강화, 해골용의 레퀴엠은 궁수·좀비·해골 마법사·해골용을 소환한다. 최대 소환체 수 18 및 골렘·해골용 우선 보존을 적용한다. 악보·지휘 연출과 기존 소환수의 실제 공격을 함께 보여준다.

## 정승욱 · 리치

군단 소환을 없애고 성물함과 영혼 소비를 중심으로 재구성했다.

- 영혼 수확: 실제 투사체 충돌 시 피해와 영혼 1개. 낙인 대상 처치로 추가 수확, 최대 6개.
- 성물함 개방: 24초간 설치, 사거리 330에서 1.2초마다 공격. 주변 적 처치로 영혼 수확. 자동사냥 시 만료 또는 이동에 맞춰 재설치.
- 혼령 방벽: 영혼 최대 3개를 소비해 회복·보호막. 자동 사용은 부상 또는 근접 위험 때로 제한.
- 사멸 의식: 성물함을 준비한 뒤 영혼을 소비하고 0.8초 후 범위 타격. 450% + 영혼당 80%. 자동 사용은 영혼 3개 이상.

성물함은 실제 공격하는 설치물이며 부활 효과는 없다. 기존 군단형 리치와 전투 방식이 달라 전체 진행 속도의 장기 균형은 추가 실전 평가 대상이다.

## 검증

반복 자동사냥의 융합·복귀 비중, 사원소 고유 공격, 궁극기 사망 취소, 소환수 수와 보존, 영혼탄 충돌, 영혼 상한·소비, 지연 타격, 자동 성물함·궁극기 사용, 336개 미리보기 및 유한 좌표 렌더링을 검사했다. 투명 8프레임 원소 융합·리치 의식 이미지는 내장 이미지 생성 도구로 제작했다. 런타임은 프레임 아틀라스를 재생하고 GIF는 검토용이다.

## 공격 이미지

불꽃 폭발·파도·회전 바람날·지면 돌출·사원소 융합 공격의 다섯 아틀라스를 각각 사용한다. 화염·대지 폭발은 실제 반경에 맞추고 바람날은 실제 340 직선 범위에 맞춰 그린다. 융합체는 개별 원소의 판정과 함께 별도의 사원소 공격 연출을 사용한다.
