# 스킬 강화 UI 개편

성장 로직·강화 비용·최대 단계·골드 차감·저장·전직 상속은 변경하지 않는다. 기존 `upgradeSkill`을 호출하는 표현 계층 변경이다.

- 데스크톱은 네 기술 목록과 선택한 기술 상세. 모바일은 네 개 선택 버튼과 단일 상세.
- 캐릭터/직업/보유 골드, 스킬별 강화 단계와 상태, 기술 효과·자원·재사용·습득, 현재→다음 표시를 분리한다. 캐릭터와 혼동하던 기술Lv를N강으로 바꾼다.
- 하단 고정 비용·보유/부족/강화 후 골드·상태와 강화 버튼. 레벨 부족/골드 부족/미습득/최대 강화/도달 불가능한 성장 조건을 구분한다.
- 강화 완료 시 선택한 기술을 유지하고 새 단계·골드·강화 결과·진행 바를 즉시 갱신한다.
- 같은 창에서 기본 연출 펼치기/접기/다시 재생. 별도의 프리뷰 게임을 사용하며 실제 캐릭터 자원·재사용·진행을 변경하지 않는다. 기술 전환/접기 시 프리뷰 상태를 교체/해제한다.
- 전직 시 네 기술 동시 해금이라는 현행 안내로 변경한다. 시작 직업의 개별 습득 조건은 유지한다.

## 수치 표시의 범위

직접 공격으로 확인한 기술은 기본 위력 대비 강화 보정(1+(rank−1)×0.14)을 정수%로 보여준다. 실제 대상 피해나 속박·지속시간 증가를 뜻하지 않는다는 설명을 붙인다. 일반화할 수 없는 보조 기술은 단계 비교만 표시한다. 확인된 고정 효과 다섯 종류(연막/독 묻히기/잠행/그림자 추격/원소술사 원소 공명)는 보조 효과가 현재 동일함을 명시한다. 개선하지 않은 성장 로직을 UI에서 개선된 것처럼 표현하지 않는다.

최고99레벨로 도달할 수 없는 다음 조건은 '현재 성장 한도'로 구분한다. 최대10강으로 완성됐다고 표시하거나 실제 강화 조건을 우회하지 않는다. 해당 성장 로직 수정은 별도 작업이다.

## 검증

`verify-rpg-skill-panel.mjs`:336개 기술 화면, 렌더링 무변경, 선택과 실제 엔진의 강화 가능/잠금/재화/최대/성장 제한 조건 일치, 고정 효과 안내, 미리보기/완료 피드백,스크립트 순서. 기존 계정 업로드/다운로드·교본 검증도 통과했다.

격리된 브라우저 화면에서 실제 엔진으로 강화와 골드 차감, 선택 유지·결과 표시, 기본 연출 열기·궁극기 전환, 골드 부족·성장 한도·보조 효과를 확인했다.390×844에서 가로 넘침 없이 닫기와 하단 버튼이 화면 안에 위치하는 것을 확인했다. 테스트 중 실제 사용자 저장은 사용하지 않는다.
