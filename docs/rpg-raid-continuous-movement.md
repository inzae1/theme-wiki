# 레이드 연속 이동

조이스틱과 WASD·방향키의 누름 상태를 유지하고 250ms 주기로 이동 명령을 보낸다. 손을 떼면 정지 목적지를 한 번 보낸다. 스킬 입력은 이동과 별도로 보관해 이동 때문에 사라지지 않는다. 탭 숨김·포커스 해제·창 닫기에는 누름 상태를 초기화한다.

서버 위치와 목적지를 기준으로 최대 350ms만 표시 위치를 보간한다. 서버 이동 속도·피해·판정은 바꾸지 않는다. 레이드 창이 열려 있을 때 스테이지 키 조작은 중단한다.

검증: 기존 이동 및 연습 전투 검사, 연속 입력·대각선 정규화·입력 해제·경계·예측 제한·사망/감옥 상태 검사.
