# r94: 수호 휠윈드와 대검 계열 재조정

r93의 비교는 전직 전보다 피해가 높은지에 집중했다. 다크나이트의 12마리 상대 피해는 뱅가드의 두 배 이상이었고, 자연 스테이지 생존 검증이 빠져 있었다. 이를 보완했다.

- 뱅가드 2번 기술: 강철 장벽 → **수호 휠윈드**. 이동 가능한 2초 / 8타 총560% / 반경125 / 재사용10초 / 이동속도75%. 회전 중 전 방향30% 경감, 최초 명중 적2초 도발. 중단·사망·전직 시 남은 타격 취소. 기세는 생성하지 않는다.
- 수호 자세와 회전의 피해 감소는 가장 강한 것만 적용한다. 실제 경감량은 불락의 전선의 반격에 저장한다. 보스 경직이나 무제한 회복은 추가하지 않았다.
- 회전 중 별도 도형 대검을 그리던 연출을 제거하고 원래 아바타의 회전 모션과 연속 검 궤적으로 교체했다. 워리어는 은색 단일 궤적, 뱅가드는 두꺼운 청강색 이중 궤적, 다크나이트는 보라색 잔류 궤적과 흑연 입자. 회전 타격마다 큰 참격을 중복 생성하는 대신 짧은 명중 섬광을 사용한다.
- 다크나이트의 과도한 다수 대상 피해를 낮췄다. 각성 중 실제 명중 피해의6%를 흡수하되, 회복 예산은 초당 최대체력2% 속도로 충전하며 최대2%만 보유한다. 모든 대상·타격이 한 회복 예산을 공유한다.
- 레이드에서도 수호 휠윈드의30% 경감은 시전자에게2초만 적용한다. 기존 파티 방어와 중첩하지 않으며 파티원에게 잘못5초 방어를 부여하지 않는다. 회전 계열의 서버 지속 피해도2초 안에 끝낸다. 레이드의 피해 계수·자원 처리는 기존 서버 프로필 방식이며 솔로 판정 전체와 동일하다는 뜻은 아니다.
