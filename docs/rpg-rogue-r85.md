# 윤인재 7직업 리워크 · 고강화 확률 완화 (r85)

기존 캐릭터·직업·스킬 ID, 전직 구조, 습득 레벨, 강화 단계와 저장 형식을 유지한다. 28개 기술은 `rogue-kit` 실행기로 연결했다.

- 도적: 연막 회피와 다음 급습/허점 찌르기 강화.
- 어쌔신: 단검 명중 후 약점, 무기에 독 바르기, 잠행 후 암살 연격.
- 트릭스터: 실제 날아가는 카드, 카드 표식, 미끼와 주변 카드 덫.
- 섀도우댄서: 자동 공격하는 소환수 대신 본체의 실제 명중에 호응하는 잔영. 잔영별 간격과 거리 제한 적용.
- 독살자: 비수 실제 충돌 후 독 부여, 중독 전이, 중첩 소모와 주변 피해, 지연 발사하는 궁극 맹독침.
- 팬텀: 관통 카드, 대역 표식, 경로·위치를 확인한 대역 교대, 자체 대역을 준비하는 궁극기.
- 사보추어: 감지 지뢰, 실제 투척 후 부착 시한폭탄, 설치물 원격 기폭, 자체 설치 후 순차 폭발 궁극기.

자동 궁극기가 자기 자신이 만드는 미끼·지뢰를 사전에 요구하던 조건을 제거했다. 준비물이 없는 교대·기폭·독 회수는 자원과 재사용 시간을 낭비하지 않는다. 대기 타격은 사망/전투 교체/전직 뒤 실행되지 않는다.

## 원화와 애니메이션

내장 이미지 생성 도구로 투명한 4열×7행 원화를 제작했다. `dist/rpg-fx/rogue/rogue-prompt.txt`에 프롬프트, `rogue-source.png`에 원화, `rogue-atlas.png`에 게임용 프레임을 저장한다. 직업별 GIF 7개는 동일 원화를 재생하는 미리보기이며 게임은 PNG 프레임을 실제 이벤트 시점에 재생한다. 시전 준비·투사체·명중·전염·교대·폭발의 위치와 시간이 다르고, 피해 범위에 맞춰 폭발 크기를 조절한다. 기본공격/시전은 기존 캐릭터 관절 모션으로 재생한다.

## 강화 확률

+20/25/30/35/40/45/49 성공률을 22/18/14/11/9/7.5/6%로 조정. 구간은 기하 보간한다. +0~19 성공률은 기존대로 유지하고 +10부터의 대실패는 `min(3%, 실패 전체 확률의 4%)`로 낮춘다. 표시된 확률과 실제 판정은 같은 값을 사용한다. +50 상한, 슬롯 강화, 비용, 단계 유지 실패, 대실패 시 1단계 하락은 유지한다.

대성공(+2강)은 전체 성공 확률의 12%를 차지하며, +49에서는 대성공 없이 일반 성공으로 +50에 도달한다. 별도 재료 없이 한 번의 비용으로 적용한다.

자원이 무한하고 표시 확률이 독립이라는 가정에서 대성공까지 포함한 +0→50 평균 시도 수는 약 379회다. 천장이나 보장 횟수는 아니며 골드·강화석 제약은 이 계산에 포함하지 않는다.

## 검증

- `verify-rpg-rogue.mjs`: 28기술, 자동 궁극기, 명중 전/빗나감 시 독 없음, 독 전이·소모, 빈 준비물 자원 보호, 대역 교대, 순차 폭발, 기본공격 잔영 협공, 연막 후속 강화, 소유자 변경 후 타격 취소.
- `verify-rpg-skill-lab.mjs`: 336개 미리보기, 유효한 좌표·그리기 상태, 윤인재 시전 준비 연출 28종 구분.
- `verify-rpg-raid-effects.mjs`: 336개 레이드 시각 시뮬레이션, 실제 서버 상태 불변.
- `verify-rpg-slot-upgrades.mjs`: 슬롯 강화 보존, 하락 및 확률 합계, 증가하는 실패율, +50 상한과 새 확률 곡선.
- 기존 검사·궁수·전사·치명타 검사 통과.
- 기존 `verify-rpg-promotion-skills.mjs`의 전직/습득/랭크 검사는 통과하지만 마지막 마나 비용 상수 검사는 현재 기존 데이터와 불일치(예상 5, 실제 8)한다. 이번 변경은 마나 비용을 수정하지 않았다.

레이드는 직업별 원본 연출을 사용하며 실제 피해와 보상은 기존 레이드 서버 판정을 유지한다.

## 강화 공방 UI

네 슬롯 전환, 장비 그림·현재 단계, 성공/대성공 후 전투력 미리보기, 작은 글씨의 별도 확률표, 보유/필요 재료, 하단 고정 강화 버튼으로 구성했다. 버튼에는 확률을 넣지 않는다. 일반 성공은 민트, 대성공은 금색, 실패는 회색, 대실패는 붉은색이며 글자로 결과와 단계 변화도 표시한다. 실패 결과별 실제 판정·재료·단계 변화, 대성공 +2 및 +50 상한을 검사했다.

## r86 · 그림자 외형 보정

섀도우댄서 잔영의 별도 인형 모델을 제거하고 실제 본체 아바타의 같은 프레임에서 투명 실루엣을 추출했다. 머리·안경·복장·쌍검 외형을 유지하며 보라색 틴트와 반투명도를 적용하고 본체와 같은 관절 공격 모션으로 협공한다. 그림자 GIF도 실제 본체와 잔영 협공 장면으로 교체했다. 게임·미리보기·레이드의 공통 이펙트 렌더러에 적용된다.
