# 원정대 전투 교본 / 강화석 소모 완화

팬텀 리메이크를 먼저 운영 배포(e51983f)한 다음 구현한 후속 변경이다.

## 교본

- 12개 특성, 원정대 공통 영구 해금과 캐릭터별 장착. 첫 Lv.30 캐릭터부터 전투 숙련 무료. 장착 칸은30/45/60에 1/2/3칸.
- 허브 전투 교본 카드 → 캐릭터 선택 → 추천/분류 목록 → 상세 → 금액을 표시한 구매 → 별도 장착. 가득 찬 슬롯은 교체할 항목을 지정한다. 중복 구매·중복 장착·직업 미호환 장착을 차단한다.
- 허브 정비 중에만 변경하며 레이드 화면에서는 열 수 없다. 이번 버전 전투 효과는 스테이지 사냥에 적용한다. 레이드 서버에는 교본 효과를 적용하지 않는다. 조건부 피해 보너스는 기본 전투력 숫자에 합산하지 않고 장착 효과를 보여준다.
- 교본은 확률·강화 단계가 없다. 입문8,000G, 전문16,000G, 전술24,000G. 선택한 캐릭터에게서 차감하고 해금은 전체 공유.
- 가격 근거: `r102-book-income.json`. Lv.30 1차 직업5종×3시드,19스테이지,기본 장비+5,자동전투·포션,경험치 고정,생존 보정 없음.2배속 실제10분 수입6,840~13,320G. 실제 구매 시간은 직업·장비·스테이지에 따라 다르다.
- 기존 JSON 저장에 `books` 추가. 기존 저장은 빈 장착으로 마이그레이션하며 강제로 장착하지 않는다. 동일한 검증 함수를 클라우드 업로드/다운로드와 내보내기에 사용한다. 구매·장착은 기기 저장 실패 시 원복하며 기존 클라우드 자동 저장도 호출한다. 기존 단일 세션 차단을 따르고 다른 저장을 적용하면 창을 닫는다.
- 응급 처치/마력 순환/반격/연쇄 사냥의 재사용은 누적 플레이 시간 기준으로 저장한다. 재시작·불러오기로 초기화하지 않는다.
- 치유의 여운은 기본 체력 재생으로 발동하지 않는다. 반격 준비는 지속 피해 틱이 소모하지 않는다. 소환 피해 배수는 장기 누적되지 않는다.

전용 검증: 구매/중복/재화/편집 잠금, 슬롯 해금/교체/직업 조건, 저장 정규화와 재사용 보존,12개 효과와 실제 포탑 피해·보호막 검사. 모바일390×844에서 구매 후 장착·현재 골드·장착 슬롯·닫기 확인. 테스트 화면은 실제 사용자 저장을 사용하지 않는다.

## 강화석

현재단계 n의 강화석은 `ceil((1+floor(n/4))*1.10^max(0,n-19))`로 변경한다. 기존 지수1.15를1.10으로 낮춘다. +0~19, 확률, 골드 수수료, 실패70% 골드 환급, 대성공·대실패, +50 상한은 유지한다. 이전 소모 재료를 소급 환급하지 않는다.
