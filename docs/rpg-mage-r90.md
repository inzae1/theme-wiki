# 이근호 마법사 계열 개편 · r90

7개 직업, 28개 기술의 실제 전투 처리와 미리보기·레이드 연출을 연결했다. 기존 캐릭터와 스킬 ID, 저장 진행도는 유지한다.

| 직업 | 전투 방식 |
|---|---|
| 마법사 | 마력탄, 서리 파동, 무료 마력 절약, 지연 메테오 |
| 원소술사 | 실제 명중한 화염·냉기·번개의 공명 축적과 소비 |
| 흑마법사 | 저주 축적, 흡수 회복, 체력을 지불하는 계약 |
| 아크메이지 | 삼원소 공명, 관통 번개와 연쇄, 삼원소 메테오 |
| 빙결술사 | 냉기 중첩, 9초 영구동토, 동결과 파쇄 |
| 워록 | 저주 표식·전이·수확·재앙의 순환 |
| 혈마법사 | 명중으로 모은 혈석, 혈창, 혈석 회복과 혈석 궁극기 |

## 실제 판정 수정

- 투사체는 이동 경로의 첫 적 또는 벽에 충돌한다. 화염·저주·혈석은 실제 명중 시 적용한다.
- 직선 주문은 460 사거리 내 지형에 막힌다. 이펙트도 실제 판정 길이에 맞춘다.
- 동결·저주 궁극기는 지연된 첫 타격 후 후속 소비를 처리한다.
- 필요한 중첩·혈석이 없으면 마력과 재사용 시간을 소비하지 않는다.
- 체력 지불 기술은 사망 직전 시전을 막는다. 일반 공격 3회 명중마다 혈석 1개를 얻는다.
- 마력 절약은 무료이며, 지속 중 다시 시전하지 않는다.
- 자동사냥은 중첩과 회복 필요, 궁극기 준비 상태를 고려한다. 벽에 막힌 경우 사격 가능한 위치로 이동한다.
- 보스 동결은 0.35초, 같은 대상 재동결 간격은 3초다.
- 전직·전투 전환 후 이전 주문의 지연 타격이 새 전투에 남지 않도록 차단한다.

## 직접 제작한 원화와 애니메이션

ImageGen 원화 2장과 투명 아틀라스 2장을 추가했다. 직업 계열 7종 및 화염탄·얼음창·혈창·번개 4종, 총 11개 GIF를 함께 보관한다. 게임은 아틀라스를 사용해 실제 명중 시점과 범위에 맞춰 재생한다. 28개 기술 모두 별도 원화를 갖는다는 뜻은 아니다.

- 원본·아틀라스·GIF: `dist/rpg-fx/mage/`
- 원화 제작 지시문: `prompts.txt`, `projectile-prompt.txt`
- 패킹: `scripts/build-rpg-mage-art.py`
- 데이터 생성: `scripts/build-rpg-mage-data.mjs`

레이드는 같은 새 연출을 표시한다. 레이드 서버의 독립 피해 계산 방식을 이번 작업에서 변경하지 않았다.
