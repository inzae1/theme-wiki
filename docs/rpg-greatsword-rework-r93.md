# r93: 박종찬 대검 분기

마검사 → 워리어, 룬나이트 → 뱅가드, 소울브링어 → 다크나이트. 기존 클래스·장비·스킬 ID와 전직 계보는 유지한다. 검사/검성/검귀/수라는 유지한다.

| 직업 | 역할 | 스킬 |
|---|---|---|
| 워리어 | 대검 딜러 / 보조 탱커 | 중검 내려치기, 휠윈드, 대검 받아내기, 분쇄 일격 |
| 뱅가드 | 탱커 / 제어 | 전선 강타, 강철 장벽, 선봉 수호, 불락의 전선 |
| 다크나이트 | 딜러 / 브레이커 | 암흑 검기, 흑풍회전, 암흑 각성, 종언의 대검 |

대검 분기는 기력을 사용한다. 워리어는 기세, 다크나이트는 어둠을 별도 축적한다. 이동 회전은 2초 동안 8회로 총 계수를 나누며, 같은 버튼으로 중단한다. 회전 중 다른 스킬과 기본 공격을 제한하고 이동은 75%로 허용한다. 벽 너머 피해, 사망·전투 전환 이후 잔여 피해를 차단했다. 뱅가드 전방 방어와 저장 반격은 실제 수용한 피해의 경감분을 사용한다. 장벽은 일반 적의 진입과 적 투사체를 차단하며 보스 경직은 장벽당 1회로 제한한다.

세 가지 아바타는 ImageGen으로 직접 제작한 양손 대검 실루엣이다. 방패·룬 연결·결속 망령을 재활용하지 않는다. 게임/캐릭터 미리보기/스킬 실험실의 렌더러를 연결했다. 회전 궤적·분절 장벽·검기·대검 낙하는 전용 Canvas 애니메이션이며 GIF를 사용했다는 뜻은 아니다.

## 검증

- 새 12기술: 8타 총계수, 이동, 취소·벽·사망·전환, 기세·어둠 상한, 방향 방어, 투사체 차단, 3종 100초 자동 보스전, 저장 ID 유지.
- 기존 16개 검 계열 기술, 72 전직의 즉시 스킬 해금, 60회 유료 직업 변경, 스킬 치명타, 시작 무기, 마력 예산, 캐릭터 모션, 레이드 이동 검증 통과.
- 84직업/336스킬 실제 엔진 미리보기 및 레이드 연출 검증 통과.
- 레이드 서버의 336 기술·쿨타임·피해·지원 귀속·권한·공개 API 로컬 DB 검증 통과. 레이드는 기존 서버의 7종 기술 처리로 재해석하며 솔로의 위치·기세·어둠 시스템까지 동일하다는 뜻은 아니다.
- 레벨60/+10, 레벨90/+20 동일 조건, 보스1/일반12, 3시드, 90초 자동 전투 48회로 보정. 두 2차 직업 피해가 워리어의 125% 이상. 자연 스테이지 클리어율 검증은 아니다. 상세 `data/balance/r93-greatsword.json`.
- 오래된 `verify-rpg.mjs`는 현재보다 적은 프레임 수(204)를 고정 가정하며, `verify-rpg-techniques.mjs`는 이전 연격/마법/독 기술의 내부 상태를 가정해 실패한다. 이를 통과했다고 보고하지 않는다. 최신 개별 직업 및 실제 미리보기 검증을 사용했다.
