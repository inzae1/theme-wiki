# 레이드 UI r83

- 대기실: 보스명·보스 도트 → 초대 코드 → 파티원 4칸 → 준비/출발. 긴 설명과 상시 참가자 삭제 버튼을 제거하고 참가자 관리는 접는 메뉴로 이동.
- 준비 인원, 접속 상태, 부족 인원, 출발 가능 여부를 한곳에 표시. 방장 변경과 코드 4자리 규칙은 유지.
- 전투: 화면 전체를 쓰는 독립 화면. 상단 보스 HP·시간, 좌측 파티 상태, 중앙 패턴 카운트다운, 하단 고정 스킬. 전투 중 스크롤 없음.
- 모바일 캐릭터가 너무 작아지지 않도록 전투 캔버스를 화면 비율과 카메라 범위에 맞춰 재배치. 터치 좌표를 서버의 원래 월드 좌표로 역변환. 서버 판정/데이터 변경 없음.
- 결과: 파티원마다 피해·방어·회복의 수치·비중·막대 3종 동시 표시. 자기/아군 상세만 접기. 구조·감옥 해제 횟수 유지.
- 연습 모드에서 ‘연습 기록 보기’로 현재 기록을 바로 확인 가능. NPC/무보상 안내 유지.

검증: 서버 raid-test 및 update 회귀 통과. 실제 브라우저에서 PC, 390×844 세로, 844×390 가로 전투의 scrollHeight==clientHeight, 스킬 바와 닫기 버튼의 화면 내 배치 확인. 세 가지 결과 수치 동시 표시 및 console error 0 확인.
