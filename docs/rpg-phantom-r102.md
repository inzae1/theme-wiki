# 팬텀 리메이크

기존 팬텀은 대역 생성·교대에 일반 스킬 두 칸을 사용하며, 궁극기도 안전한 교환 위치와 근접 후속 타격에 의존했다. 독립적으로 사용하는 원거리 제어·광역 공격 직업으로 변경한다. 저장/직업/스킬 ID와 비용·재사용 시간은 유지한다.

1. 망령 카드: 관통 카드 3장을 시간차 발사, 각 125%. 실제 적중에만 6초 표식.
2. 거울 회랑: 선택한 적 무리 주변에 거울 세 개. 6초 동안 1.5초 간격으로 각 45% 광역 피해와 냉기. 대역·교대 불필요.
3. 환영 감옥: 135 범위 260%, 일반 적 1.8초/보스 0.35초 속박, 표식, 0.5초 본체 무적.
4. 백귀야행: 고정 165 범위 다섯 파동 각 160%, 마지막 320%(표식 대상 25% 증가). 본체 강제 이동 없음.

거울/망령 가면/속박 사슬/표식 수렴은 전용 캔버스 애니메이션. 섀도우댄서 본체 잔영과 구분한다. 미리보기·레이드 연출도 공통 런타임을 사용한다. 레이드 서버의 기존 계수는 이 단계에서 변경하지 않는다.

전용 회귀 검사: 독립 네 스킬, 사거리 밖 자원 보존, 다수 대상 궁극기, 거울 소멸, 사망/전직/장면 변경 후 예약 타격 취소. 기존 도적 28스킬·7직업 자동 전투와 336개 레이드 연출 검사 통과.

90개 진단(두 직업×세 장면×세 시드×다섯 스킬 활성 조합, 45초)은 모두 유한. 스킬 비활성화 시 세 시드 모두 5% 이상 개선되는 항목 없음. 무한 체력/체력 보정이 포함된 진단이므로 실제 클리어·생존·레이드 밸런스 수치로 해석하지 않는다.
