# 레이드 융합 r89

허브 → 레이드 융합, 장비·가방 → 레이드 융합, 슬롯 강화 공방 → 레이드 융합, 레이드 결과 → 레이드 융합에서 접근한다.

## 보상과 성장

- 기존 레이드 결정을 같은 잔액의 융합 조각으로 사용한다. 과거 지급 기록과 잔액은 삭제하지 않는다.
- 기존 유효 기여/클리어 판정 및 한국 날짜 기준 하루 3회 제한을 유지한다. 유효 클리어마다 조각 30개, 20% 확률로 추가 융합체 1개. 무기·방어구·장신구 3부위 확률은 동일하다. 연습·실패·일일 보상 소진 후 도움 참가는 융합 보상이 없다.
- 조각 90개로 원하는 부위를 확정 제작하면서 선택한 캐릭터 슬롯에 원자적으로 장착한다. 중복 드랍은 성장 재료로 보관한다.
- 성장 최대 Lv.10. 중복 1개를 우선 사용하고, 없으면 조각 `30 × (현재 레벨 + 1)`개를 사용한다. 확정 성공이며 파괴·하락·추가 골드 비용은 없다.
- 융합체의 보유·성장은 원정대 공통, 세 부위의 장착은 캐릭터별로 설정한다. 해제에 재료 손실이 없다. 일반 장비 교체·분해·슬롯 강화와 독립적이다.

| 부위 | 융합체 | Lv.1 → Lv.10 |
| --- | --- | --- |
| 무기 | 거신의 송곳니 | 공격력 +6% → +24% |
| 방어구 | 거신의 심장 | 최대 체력·방어력 각각 +8% → +35% |
| 장신구 | 거신의 수정안 | 공격력·최대 체력 각각 +3% → +12% |

같은 능력의 융합 보너스는 먼저 합산한 뒤 기존 장비 능력치에 한 번 적용한다. 실제 기본공격·스킬·소환수의 공격력, 체력, 방어력, 전투력 계산과 랭킹 계산에 반영한다. 레이드는 입장/새 출발 시 서버 지갑을 기준으로 공격력·최대 체력을 반영하며, 방어력 보너스의 30%를 레이드 피해 감소율로 적용한다. 감소된 실제 피해는 자기 방어량에 기록한다. 진행 중인 한 판의 전투 수치는 도중에 재계산하지 않는다.

## 저장과 동시 요청

`server/raid/raid.sql` 적용 후 `server/raid/fusion.sql`을 적용한다. 현재 게임 전용 프로젝트 `fxkdlcqheyireuuykzzw`에 적용·검증했다. 기존 연결 도구 계정에는 이 프로젝트가 없어 로그인된 대시보드 SQL 편집기로 수행했다.

재료·보유 융합체·성장·캐릭터별 장착은 비공개 `rpg_raid.wallet`에서 서버가 관리한다. 보상은 기존 `(runId,userId)` 원장의 AFTER INSERT 트리거에서만 추첨하여 중복 요청의 재추첨을 막는다. 제작·성장은 서버 잔액 검사와 행 잠금, 예상 revision 검사로 처리한다. 재시도나 다른 기기의 오래된 요청은 중복 차감 대신 충돌 응답으로 최신 상태를 다시 확인한다.

기존 클라우드 저장 트리거를 보존하고 별도 저장 트리거가 `raidFusion`을 서버의 정식 상태로 덮어쓴다. 클라이언트가 보유량·레벨·소유자를 조작한 저장은 반영되지 않는다. 로그인·클라우드 불러오기·레이드 응답에서 최신 상태를 기기에 반영한다. 장비 성장과 원정대 저장 revision은 독립되어 레이드 지급이 다른 기기의 일반 사냥 저장을 덮어쓰지 않는다.

공개 RPC는 invoker이며 비공개 내부 함수에서 `auth.uid()`와 소유권을 검사한다. 익명 호출, 다른 계정 상태 조회, 인증 사용자의 지갑 직접 수정은 허용하지 않는다. 기존 RLS·테이블 권한은 유지한다. Supabase Advisor Center 확인 결과 이 변경과 관련된 새 항목은 없었고 기존 랭킹 함수·Auth·미사용 인덱스 항목만 표시됐다.

## 검증

- `scripts/verify-rpg-raid-loot.mjs`: 실제 공격력·체력·방어력과 전투력 증가, 저장 왕복, 기존 저장 호환, 캐릭터별 장착, 기존 슬롯 강화와 함께 적용, 장비 교체 유지, 레벨 상한, 미리보기 비용·중복 성장.
- `server/raid/verify-fusion.sql`: 실제 DB에서 테스트 전용 사용자와 방을 트랜잭션 안에 생성하고 전부 롤백한다. 원자적 제작/장착, 잔액·오래된 revision 거절, 타 계정 조회 거절, 조작 저장 교정, 중복 성장, 실제 레이드 command 보상·반복 poll·원장 충돌·하루 3회 제한, 해제 효과, authenticated 역할의 조회·클라우드 저장을 검증했다.
- 로그인·클라우드·랭킹·슬롯 강화·업데이트·기존 기사/도적/박천빈 스킬 및 전체 336개 미리보기·레이드 연출 회귀 검사 통과.
- 로컬 격리 UI에서 장착 → 중복 성장, 확정 제작, 캐릭터 전환, 해제를 확인했다. 390×844 모바일에서 닫기 버튼과 내부 스크롤을 확인했다. QA 데이터는 실제 원정대와 분리하며 QA 페이지는 배포하지 않는다.
