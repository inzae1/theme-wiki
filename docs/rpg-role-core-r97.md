# 역할 표시 단순화와 공통 처리 1단계

2026-10-23

## 현재 완료 범위

- 박종찬 워리어·뱅가드·다크나이트 SD 아바타 재제작·공개 배포 완료. 기존 4직업 외형은 유지하고 몸 높이·발 앵커를 맞췄다.
- 84개 직업의 화면 역할은 딜러·탱커·힐러·서포터 네 가지로 제한했다. 실제 현재 기능의 특징을 작은 태그로 표시한다.
- 전직 선택·직업 상세 미리보기·스킬 미리보기·레이드 대기실에서 같은 표시 데이터를 사용한다. 브레이커·제어형은 플레이어에게 독립 파티 역할로 요구하지 않는다.
- 주역할 불일치 13개는 아직 실제 스킬 개편 전이다. 현재 민스트럴·워록 등은 공격 중심인 상태를 표시하고, 상세 미리보기에서만 ‘개편 예정’ 목표를 별도 표시한다. 미구현 회복·무력화를 현재 기능처럼 표시하지 않는다.

## 공통 처리

`dist/rpg-role-core.js`는 시전자·표적·팀·거리·시각을 명시한 단일 이벤트로 치유/보호막/강화/약화/마력 지원/제어/무력화/피해를 처리한다. UI 역할 이름으로 효과를 추측하지 않는다.

- 강화·약화는 시전자·기술별 값과 만료를 보존하고 같은 계열 최댓값만 적용한다.
- 치유는 실제 부족 체력만 실적으로 집계하며 네 파동이 한 시전의 전체 예산을 공유한다.
- 보호막은 하나의 소모 풀이다. 약한 보호막을 적립하거나 강한 보호막의 만료를 연장하지 않는다. 방어 실적은 실제 흡수와 실제 생존 피해 방지로 계산한다.
- 무력화는 시전별·보스별 누적 상한을 사용한다. 무적·빗나감·재무력화 제한 중 기여를 저장하지 않는다. 공격력·치명타 수치로 무력화가 증가하지 않는다.
- 일반 적의 하드 제어는 종료 후 공통 2초 면역이다. 보스는 허용 차단 창 또는 공유 8초 대기의 제어 전환을 사용한다.
- 마력 지원은 시전자 자신과 기력·분노를 제외하며, 여러 서포터가 동일한 마력 지원 창을 중복 지급하지 못한다.
- 중복 이벤트, 시전자 사망, 죽은 표적, 유효 범위 이탈을 처리한다. 소생 기술과 일반 치유를 혼동하지 않는다.

서버 대응은 `server/raid/role-core.sql`의 비공개 함수 6개다. 기존 전투/저장 테이블을 변경하지 않는다. 함수는 권한 상승 없는 invoker이며 검색 경로를 고정하고 PUBLIC/anon/authenticated 실행 권한을 회수한다. 서버가 검증한 프로필·시전 ID만 전달하는 내부 용도다.

## 검증

- `scripts/verify-rpg-role-core.mjs`: 실제 공통 처리 모듈의 동작 27개 검사 통과.
- `server/raid/verify-role-core.sql`: 같은 입력에 대한 브라우저용 모듈과 실제 PostgreSQL 서버의 전체 상태 대조 12/12 일치.
- `scripts/verify-rpg-skill-lab.mjs`: 기존 84직업·336기술 미리보기 검사 통과.
- `scripts/verify-rpg-raid-effects.mjs`: 기존 336기술 레이드 연출 검사 통과.
- 역할 표시 데이터는 84직업을 모두 포함하며 13개 개편 목표가 기존 재설계 문서와 일치하는지 확인했다.

## 다음 연결 범위

현재 공통 처리와 서버 비공개 함수는 검증됐지만, 기존 사냥/레이드 스킬 어댑터는 아직 새 공통 처리로 전환하지 않았다. 따라서 13직업·52스킬이 실제로 개편됐다고 표시하지 않는다.

이후 순서는 민스트럴·아이돌·워록의 실제 스킬 연결, 7개 주 브레이커, 독 연금술사·엘리멘탈로드·리치다. 각 묶음은 사냥과 레이드를 함께 연결하고 60·90레벨 사냥/보스, 4인 유효 치유·방어·무력화·자원 소비를 측정한 뒤 구현 완료로 전환한다.
