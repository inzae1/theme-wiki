# 역할 개편 1차 반영 — 민스트럴·아이돌·워록

2026-10-23. r97의 공통 판정 위에 **3개 직업 / 기존 ID 12개 기술**을 실제로 연결했다. 나머지 불일치 10직업은 설계 단계이며 화면에도 개편 예정으로 남긴다.

## 적용 내용

- **민스트럴 / 힐러:** 첫 악절 명중 또는 적 없는 긴급 시전으로 낮은 체력의 아군 회복. 이동 방어 연주와 4회 지속 회복, 최근 유효 회복 50% 재연, 합주를 소비하는 4회 협주곡. 합주 0에도 긴급 궁극기 가능. 궁극기는 합주를 돌려주지 않는다.
- **아이돌 / 서포터:** 실제 음파 3발 명중 후 공유 취약 4%. 이동 무대의 공격력·공속 10%, 안무의 이동속도 15%와 체력 5% 한도 보호막, 인기별 앙코르 보조 회복. 기존 무대의 추가 기본공격·공속 강화와 중복하지 않는다.
- **워록 / 서포터:** 명중 저주의 적 공격 약화 8%, 전이의 공유 취약 6%, 재앙의 약화 12%·취약 8%. 저주 수확의 회복은 자신만 받는다. 저주를 소비해도 지원 인장은 남는다.

사냥은 단독 캐릭터 기준, 레이드는 거리 안의 실제 동료를 대상으로 같은 공통 회복·보호막·최댓값 강화·약화 규칙을 사용한다. 레이드 오라는 1초 주기로 범위를 갱신하고 범위를 벗어난 대상의 강화는 최대 약 1.1초 후 사라진다. 사망하면 예약 회복과 오라가 취소된다. 재도전에는 이전 전투의 역할 상태가 남지 않는다.

마력 6% 아군 지원은 이번 적용에서 제외했다. 현재 레이드는 마력 자원 체계가 없으므로 실제로 작동하지 않는 기능을 기술 설명에 표시하지 않는다. 사냥 자체의 기존 마력 회복·소모 규칙은 유지한다.

## 시각 효과

기존 직접 제작한 음표·회복 스프라이트와 전용 안무·저주 연출을 사용하며 회복 타이밍, 방어 음표, 보호막, 지속 약화·취약 인장을 추가했다. 협주곡의 회복 빛은 시전자에, 공격 음표는 적에게 따로 표시한다. 이번 변경은 새 GIF 제작이 아니다. 레이드의 개별 타격 알림이 궁극기 전체 연출을 반복 실행하던 경로는 제외했다.

### 지속 피해 비교

90초, 60레벨/+10·90레벨/+20 기본 장비, 레어 포션, 보스 1마리 또는 일반 몹 12마리, 시드 3개. 체력을 1 이상으로 고정한 지속 피해 비교이므로 자연 클리어 판정은 아니다. 이번 3직업과 시작·부모 전직을 합쳐 96회 실행했다.

| 직업 | 보스 피해 / 부모 전직 | 다수전 피해 / 부모 전직 |
|---|---:|---:|
| 민스트럴 | 1.20~1.21배 | 2.45~2.46배 |
| 아이돌 | 약 1.53배 | 2.77~2.78배 |
| 워록 | 1.72~1.89배 | 2.34~2.49배 |

민스트럴의 기존 다수전 보정 3.6397은 새 광역기에 과도하게 적용되어 1.2로 재조정했다. 보스 보정은 1.06으로 분리했다. 회복량을 이 피해 보정으로 증폭하지 않는다.

레이드 정지 표적 90초 비교에서는 부모 전직 대비 민스트럴 약 1.17배, 아이돌 약 1.15배, 워록 약 1.45배의 본인 피해를 기록했다. 치명타·핵 노출·동료 기여·생존·이동은 제외한 제한된 비교이다.

### 체력 고정 없는 스테이지 표본

같은 기본 장비·레어 자동 포션·시드 1729, 60레벨 81스테이지와 90레벨 141스테이지, 첫 클리어·사망 또는 240초에서 종료했다. 새 직업 6개 표본 중 5개는 클리어했고, 아이돌 90레벨/141스테이지는 67마리 처치 후 사망했다. 부모 전직은 같은 조건에서 모두 사망했다. 따라서 전직 후 약화는 관측되지 않았지만 **모든 장비·스테이지에서 무조건 클리어한다는 의미는 아니다.**

1. `node scripts/build-rpg-support-data.mjs`
