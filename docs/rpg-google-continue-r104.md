# 구글로 계속하기 추가 확인 제거

기존의 '이 기기에서 이어할까요?' 확인창 대신, 사용자가 구글로 계속하기를 누르거나 해당 OAuth 절차가 돌아왔을 때 한 번에 세션 전환→최신 클라우드 다운로드→허브로 이동한다. 구글 로그인 자체의 동의·계정 선택 화면은 변경하지 않는다.

- 서버의 기존 강제 전환 명령을 명시적인 계속하기 행동에서만 사용한다. 단일 소유자 토큰·저장 revision·다른 계정 격리·통합 계정 차단은 유지한다.
- 이미 이 화면에서 클라우드를 채택해 플레이 중이면 최신 기기 진행을 오래된 원격 저장으로 다시 덮어쓰지 않고 해당 진행을 이어간다.
- 연결하는 동안 기기 전투를 멈춘다. 새 기기로 전환할 때는 자동 저장을 먼저 멈추고, 세션 획득 후 최신 원격 저장을 읽는다. 기존 다운로드의 기기 백업과 검증을 사용한다. 첫 계정 연결의 게스트 데이터 선택·원정대 이름 설정은 유지한다.
- 접속을 잃은 화면은 정지한다. 새 질문형 제목 대신 상태와 '구글로 계속하기' 버튼을 표시한다. heartbeat·토큰 갱신·접속 상실 이벤트에서는 자동 재탈환하지 않는다.
- 중복 클릭은 단일 작업으로 처리한다. OAuth/로그인 진입 표시는 처리 시작에 소비하여, 오류 후 나중에 탭을 새로고침하는 것만으로 재탈환하지 않는다.

검증: continue helper의 정상/활성 기기/첫 연결/통합 차단/네트워크 실패, 실제 account UI 모듈의 VM 테스트(로그인만으로 탈환 없음, 이중 클릭 한 번 처리, 최신 저장 채택, 허브 이동, 이전 화면 차단, heartbeat 재탈환 없음), 기존 cloud-account 저장 검증, PGlite 서버의 단일 소유자/전환/오래된 저장 거부/계정 격리/통합 계정 차단 검사 통과. 운영 계정이나 실제 진행을 사용해 로그인·전환하지 않는다.

서버 SQL과 인증 권한은 변경하지 않는다.
