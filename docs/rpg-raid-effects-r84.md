# r84 유니크 이하 분해 선택 / 레이드 직업 스킬 연출 연결

## 분해
가방의 빠른 선택에 ‘유니크 이하 선택’을 추가. 레어·에픽·유니크까지 선택하며 착용 장비와 레전더리는 제외. ‘미착용 전체’ 대신 ‘선택 해제’를 제공해 빠른 선택으로 레전더리가 섞이지 않도록 변경. 분해는 기존 선택 확인 절차를 유지하고 슬롯 강화는 보존. 개별 장비의 수동 분해 규칙은 변경하지 않음.

## 레이드 연출
원인: 서버가 보낸 slot 포함 스킬 이벤트를 공통 선/교차 타격으로만 표시하고 기존 직업별 VFX 실행기에 전달하지 않았음.

- rpg-raid-effects.js에서 hero/cell/slot으로 현재 스킬 데이터와 원본 연출 시뮬레이션을 연결.
- 일반 스킬과 궁극기의 원본 시전/실제 타격 연출, 지대·소환수 및 모션을 재사용. 스킬 버튼 이름도 현재 스킬 데이터 우선.
- 서버 이벤트를 owner/slot/at로 중복 제거. 최대 16개·3.2~7초의 렌더 인스턴스 및 시간 단계 제한.
- 원본 스킬 준비 상태가 필요한 연출은 미리보기의 준비 로직을 재사용. 이 시뮬레이션은 렌더링 전용이며 서버의 피해·회복·보상·클라우드 저장을 수정하지 않음. 실제 레이드 전투 밸런스/판정은 기존 서버 규칙 유지.
- 내부 시뮬레이션의 가짜 전투 수치/미터 텍스트는 표시하지 않음. 기존 실제 서버 피해 표시는 유지.
- rpg-preview의 createSimulation 공개 및 drawObjects의 renderPhase 옵션은 기존 미리보기 기본 동작을 보존.

검증: verify-rpg-raid-effects — 336 스킬, 1023 전용 이벤트, 12328 스프라이트 호출, 유한 좌표·save/restore 균형·중복 방지·수명 상한·서버 상태 불변 통과. 기존 skill-lab 336 미리보기, raid 서버 회귀 통과. 실제 브라우저에서 수동 궁극기/전용 깃발 연출 확인, 콘솔 오류 없음.
