# 개테천온라인 — 검색 자료를 반영한 48개 최종 전직 변경 명세

상태: 설계안. 아래 스킬명·규칙은 개테천온라인용 제안이며 원작 게임의 스킬을 그대로 가져온 목록이 아니다. 84개 전체 직업 중 최종 전직 48개의 목표를 먼저 확정한다. 시작 12개와 1차 24개는 이 규칙을 단계적으로 배우도록 연결한다.

## 공식 자료와 적용 범위

- [FFXIV 음유시인](https://eu.finalfantasyxiv.com/jobguide/bard/): 노래와 직업 게이지 구조 참고. 여기서는 파티 지원을 1인 사냥에 맞는 자기 강화·화음 공격으로 재설계한다.
- [FFXIV 기공사](https://eu.finalfantasyxiv.com/jobguide/machinist/): 열기 게이지 등 준비와 방출의 전투 구조 참고. 마이스터의 직접 전투와 메카닉의 설치 전투를 분리한다.
- [Guild Wars 2 엔지니어](https://www.guildwars2.com/en/the-game/professions/engineer/): 무기 키트 교체와 포탑의 서로 다른 운용 참고. 무기 변형·진지 구축·시약 반응을 별도 직업으로 분리한다.
- [Diablo IV 드루이드 소개](https://diablo4.blizzard.com/en-us/): 곰·늑대의 실제 변신과 야생 동료라는 외형·역할 구분 참고. 변신 중 기본공격만 가능하다는 규칙은 사용자가 지정한 본 게임 규칙이다.

검색에서 확인한 구조를 참고하되 아래 수치·스킬 구성·자동 전투 조건은 본 게임을 위한 설계 판단이다. 기존 마력 무자연회복·기력 자연회복·타격 시 분노 증가, 15초 무제한 회복제 규칙은 유지한다. 열기·연격·혈석 등은 별도 보조 규칙이다.

| 리치 | 다수 해골·망령 부대를 유지하고 시체 자원으로 보충한다. | 해골 모집 / 시체 회수 / 군단 강화 / 망자의 행진 |
| 데스마스터 | 소수 사신·죽음 표식·영혼 소비 처형으로 강한 적을 마무리한다. | 사신 소환 / 죽음 표식 / 영혼 수확 / 사형 선고 |

자동 전투: 정령왕은 한 마리, 융합은 재료를 소비, 리치는 다수 약한 개체, 데스마스터는 소수 정예로 소환 상한부터 다르게 한다.

## 실제 판정과 이펙트의 완료 조건

1. 검격은 칼이 지나간 호·직선 범위, 포격은 착탄 지점, 브레스는 부채꼴, 빔은 지속 직선 판정을 사용한다. 모두 같은 원형 즉시 피해로 처리하지 않는다.
2. 다단 공격은 시각 효과와 동일한 시점에 나눠 타격한다. 운석·포탄의 피해는 착탄 전에 발생하지 않는다.
3. 반격 직업은 실제 방어 성공 기록이 필요하다. 보호막 수치만 올리고 반격이라고 표시하지 않는다.
4. 룬·지뢰·포탑·식물은 각각 남는 물체와 작동 조건이 있다. 설치 위치가 전투 결과를 바꿔야 한다.
5. 분신·야수·해골·정령왕·융합체는 개체 수·크기·이동·공격·수명·대상 선정이 다르다.
6. 독·저주·냉기·낙인은 독립 상태로 관리한다. 중첩 상한, 갱신, 전염, 소모 규칙을 명시한다.
7. 보스는 처형 즉사·무한 동결·영구 차단을 허용하지 않는다. 보스 전용 추가 피해와 제어 저항을 사용한다.
8. 야성드루이드는 곰·늑대 동안 다른 스킬을 잠그고 강화 기본공격만 가능하다. 늑대 자동 반복 때문에 곰을 못 쓰는 문제도 함께 해결한다.
9. 미리보기는 해당 기술의 실제 이벤트·이동·소환을 공유한다. 근접/원거리 거리와 단일/광역 대상 수를 기술마다 구분한다.

## 우선 수정할 현재 문제

- 사제 작은 치유: 회복이 실제로 발생하도록 수정.
- 중복 독 부여: 강한 독이 약한 독으로 덮어써지는 처리 수정.
- 분노 직업의 회복 버프: 자연 회복률 0을 곱하는 무효 효과 대신 타격 획득량 등 유효한 규칙 사용.
- 팬텀/사보추어, 마이스터/메카닉, 검무가/별무희, 리치/데스마스터의 공유 기술 구성을 우선 해체.

## 검증 및 적용 순서

오류 수정 → 시간차 타격·범위·이동·상태 중첩 기반 기능 → 48개 직업별 효과 → 모션·이펙트 → 자동 전투 → 밸런스와 미리보기.

동일 레벨·장비로 단일보스, 다수 몬스터, 장기전, 이동 위협 네 상황을 각각 비교한다. 피해량 외에 처치 시간·생존·이동·회복제 사용·설치/소환 유지·자원 소진을 기록한다. 네 전직은 최소 두 개 이상의 운용 축에서 달라야 하며, 동일 4기술 구성을 이름·색·계수만 바꿔 공유하면 실패다.
