# r92 전직·사냥·레이드 개편 결과

같은 레벨·장비·자동 전투·세 난수 시드로 변경 전후 각각 2,592회 비교. 합성 90초 단일/12마리 측정에서는 사망으로 검사 시간이 달라지지 않도록 체력을 최소 1로 유지했으며, 실제 생존·클리어는 별도 자연 전투로 비교했다. 모든 저장 조합의 보장이 아니다.

| 검사 | 변경 전 | 변경 후 |
|---|---:|---:|
| 후반 일반 사냥 통과 | 34/144 | 144/144 |
| 후반 보스 구간 통과 | 125/144 | 144/144 |

후반 비교 조건: 90레벨·2차 직업 48개 × 3시드, 전 부위 레전더리/공격 접사/+30, 희귀 포션 자동 사용, 141/142구간, 제한 180초. 보스 자체 HP는 낮추지 않았다.

## 전직 성장

전직 직후 60레벨의 추가 1,008회 검사와 90레벨 비교에서 48개 2차 모두 동일 조건의 단일·광역 지속 피해에서 시작 직업과 해당 1차를 15% 이상 앞섰다. 같은 전직끼리 모두 같은 피해로 맞춘 것은 아니다. 방어·회복·기동 성격은 유지한다. 보정표는 실제 판정의 상대 계수이며 표시 공격력이나 저장 장비 수치를 변경하지 않는다.

리치는 성물함이 처치 없이도 영혼을 생성하고 주변 적을 타격한다. 영혼 수확에도 주변 타격이 생겼으며 궁극기 준비 직전에 방벽이 영혼을 먼저 소모하지 않도록 했다.

일반몹 체력·공격력 증가를 후반에서 완만하게 하고, 0.8초 동안 네 마리를 초과해 겹쳐 들어오는 일반몹 피해는 25%만 적용한다. 첫 챕터와 보스의 체력·공격력은 그대로다. 몬스터 수와 15마리/8초 생성 리듬도 유지한다.

## 레이드

84직업·336기술에 이름·서명·고유 재사용 시간·전직 공격 예산·공격/지속피해/소환 지속공격/회복/보호막/피해감소/강화의 7종 판정을 등록했다. 서버만 계수를 결정하고, 기존 융합·보상·계정 보호를 유지한다. 소환과 지속피해는 시간 경과에 따라 실제 보스 체력을 감소시킨다. 운영 DB의 진행 중 전투가 0인 것을 확인하고 적용했다. 운영 DB에서도 336개 기술 시전과 지속 판정을 확인했으며 임시 검사 데이터는 남기지 않았다.

레이드 전용 균형으로 재해석한 프로필이다. 스테이지의 모든 위치·개별 자원·중첩·처형 조건 336개가 서버와 완전히 동일해진 것은 아니다. 원본 스킬 연출은 유지한다.

## 검증

- verify-rpg-balance: 48개 전직 성장, 2,592회 유한값, 잡몹 동시 압박 완화, 리치 영혼/광역 검사.
- 로컬 Postgres 검증: 84직업·336회 시전, 7종 판정, 재사용 시간, 실제 서버 tick, 회복/보호, 호출 권한, public create/skill 경로 통과.
- 직업·스킬·마력·계정과 보상 관련 22개 회귀 검사 통과. 오래된 리치 군단/고정 마나 비용 테스트는 현재 설계에 맞게 갱신했다.

## 재현

`node scripts/audit-rpg-balance.mjs` 및 `node scripts/audit-rpg-balance.mjs 60` 후 `node scripts/verify-rpg-balance.mjs`. 원본 참조는 data/balance/r91-baseline.json, 계수 생성은 build-rpg-balance.mjs. 레이드 생성은 build-rpg-raid-profiles.mjs와 build-rpg-raid-balance.py. 검사 시뮬레이션은 외부 계정이나 저장 데이터를 쓰지 않는다.
