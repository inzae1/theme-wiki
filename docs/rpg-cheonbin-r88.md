# 박천빈 전투·연출 점검 (r88)

| --- | --- | --- |
| 격투가 | 연타·밀어차기·호흡·정권 | 붉은 권투장갑, 금빛 타격 |
| 기공사 | 호흡 중 기본공격으로 기 축적, 장풍·폭발에 소비 | 청록 나선 기탄, 손으로 받아치기 |
| 드루이드 | 구속·일회성 가시 함정·회복·늑대 소환 | 실제 가시가 달린 덩굴, 잎과 생명력 |

기존 직업·스킬 ID와 변신 중 기본공격 전용 구조를 유지했다. 새 원화는 공통 그림 하나를 모든 직업에 붙이는 방식 대신, 7개 직업의 소재를 구분해 프레임·위치·크기를 실제 이벤트에 연결했다. GIF는 확인용이며 실제 게임은 투명 PNG 아틀라스를 재생한다.

## 확인하고 수정한 문제

- 무적·회피 공격에도 발생하던 기공 받아치기 및 해병 방어량 누적을 실제 방어에만 적용. 반격은 가까운 적, 지형 시야, 0.5초 간격을 확인한다.
- 기공포 사거리 480 고정을 스킬 실제 사거리로 변경. 판정과 빔 그림 모두 장애물에서 멈춘다.
- 기공탄·식물 가시가 앞의 적이나 벽을 통과하던 문제를 6픽셀 단위 충돌 검사로 수정.
- 격투 근접기 판정을 설명의 125 범위와 일치시킴. 다수 대상 자연 기술도 지형 시야 검사.
- 자연의 숨이 정확히 4회, 최대 체력 20%를 회복하도록 시간 누적 처리.
- 살아 있는 가시 식물을 재사용 대기시간마다 교체하던 자동 시전 방지. 사망한 시전자와 만료된 함정의 추가 피해 방지.
- 늑대·곰이 몬스터 스프라이트를 재사용하던 표현을 새 전용 모습으로 변경. 검은 모자·붕대를 공통 특징으로 사용. 실제 공격 시 프레임이 바뀌고 변신 종료 시 원래 모습으로 복귀.

## 검증

28개 스킬, 실제 피해 방어·무적·회피·반격 간격, 지형과 기공포 그림 끝점, 먼저 닿은 적 충돌, 회복 20%, 식물 재설치·사망, 변신 3종·공격 프레임·시간 종료를 검증했다. 전체 336개 미리보기 및 레이드 시각 시뮬레이션도 통과했다. 레이드 서버 피해 계산은 변경하지 않았다.
