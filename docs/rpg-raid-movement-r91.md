# 레이드 이동과 스킬 조작 · r91

레이드 자동 전투도 서버의 실제 좌표로 이동한다. 근접은 보스 중심에서 86, 원거리·회복은 235 거리를 두고 파티 번호별로 흩어진다. 기존 서버 move 명령을 사용하므로 다른 참가자에게도 같은 위치가 보인다. 클라이언트에서 체력이나 피해를 만들지 않는다.

직접 바닥·방향키·WASD·모바일 조이스틱을 조작하면 3초간 자동 접근을 중단한다. 균열 회피는 플레이어가 직접 조작한다. 쓰러지거나 감옥에 갇힌 경우 자동 이동을 보내지 않는다. 구조 명령이 자동 접근보다 우선한다.

화면 좌표 보간은 프레임 속도와 무관하게 처리하며 실제 좌표 변화로 걷기 모션을 판정한다. 전투 시작 시 이전 방의 보간 좌표를 비운다. 연습도 같은 거리 배치를 사용하며 기본 공격 사거리를 검사한다.

스킬창은 스테이지의 원형 버튼·쿨타임 충전 테두리·기술 이름·궁극기 강조를 따랐다. 기존 레이드 서버 재사용 시간과 피해/지원 역할은 유지한다. 감옥·사망 상태와 남은 시간을 접근성 이름에도 표시한다. 4개 스킬의 1~4키 및 모바일 가로·세로 배치를 유지한다.

검증: verify-rpg-raid-navigation, verify-rpg-raid-effects(336개), verify-rpg-raid-loot 통과. 연습 화면에서 이동과 원형 스킬창 확인.
