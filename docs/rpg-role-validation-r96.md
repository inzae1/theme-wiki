## 확인한 범위

- 기존 r95 전투 엔진 408회: 60·90레벨, 동일한 직업별 기본 장비 +10/+20, 90초 지속 피해, 단일 보스/12마리, 3개 시드. 시작·부모 1차·대상 13개 2차를 비교했다.
- 생존을 강제로 유지한 지속 피해 측정이다. 자연 스테이지 클리어율·실제 파티 생존·신규 역할 성능 측정으로 해석하면 안 된다. 희귀 회복/마력 포션을 허용했다.
- 제안 규칙의 별도 수학 모델 31개 검사: 회복 상한, 광역 파동 분할, 초과 회복 제외, 강화 만료 복귀, 보호막 중복, 캐스트별 무력화 상한, 무적·빗나감, 재무력화 제한, 하드 제어 면역, 보스 제어 변환, 마력 지원 중첩. 게임 런타임의 동작을 보장하는 검사는 아니다.
- 직업 셀·52개 저장 스킬 ID 유지 확인.

## 아직 실전 합격으로 표시할 수 없는 이유

- 공용 역할 런타임과 레이드 다중 효과·대상 처리가 아직 미구현
- 52개 스킬의 공격 예산 재배분·회복 범위·치유 우선순위 수치 미확정
- 새 스킬로 자연 스테이지·4인 레이드·실제 생존/치유/무력화 실측 필요

- 자연 스테이지 클리어율, 4인 실제 유효 치유/피해 방지/무력화 간격, 제어 체감, 영상·모바일 가독성은 아직 신규 기능으로 확인하지 않았다.

## 아바타 추가 점검

기존 `jongchan.png`와 신규 `jongchan-greatsword-avatars.png` 원본을 직접 비교했다. 기존은 큰 머리·짧은 몸·굵은 외곽선·큰 색면의 SD 형태다. 워리어·뱅가드·다크나이트는 머리가 상대적으로 작고 팔다리가 길며 갑옷 명암·윤곽이 촘촘하다. 단순 해상도 변경으로 해결할 수 있는 차이가 아니며, 기존 얼굴과 SD 비율·외곽선 굵기·논리 픽셀 크기를 기준으로 의상과 대검을 다시 맞춰야 한다. 이번 검증에서는 아바타 파일을 교체하지 않았다.
